# Task 001: Project Setup

## Objective
Initialize the Python project with all required tooling.

## Requirements
1. Create `pyproject.toml` with project metadata
2. Set up `requirements.txt` with all dependencies
3. Create `.env` file with default configuration
4. Create `.gitignore` file
5. Set up `app/` package structure

## Files to Create
- `backend/pyproject.toml`
- `backend/requirements.txt`
- `backend/.env`
- `backend/.env.example`
- `backend/.gitignore`

## Definition of Done
- Project structure matches `ARCHITECTURE.md`
- Dependencies install cleanly with `pip install -r requirements.txt`
- Environment variables load correctly
